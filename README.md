Welcome! This is my shopping list app.

The motivation behind this project was to create an easy and practical way to build shopping lists on the go. The app supports creating, editing, viewing, and deleting both individual products and entire lists. As soon as you add a product, the backend handles the total calculation for you, eliminating the need for a calculator.

This application was built to study and hone my Full Stack skills, although my wife and I already use it for our own grocery shopping.
